# 📊 HR Analytics Dashboard | Power BI

An interactive **HR Analytics Dashboard** built using **Microsoft Power BI** to analyze employee attrition, demographics, job satisfaction, education, salary, age, and years of service.

The dashboard includes an interactive **Light Mode / Dark Mode toggle**, allowing users to switch between two visual themes for a better viewing experience.

## 📌 Project Overview

The HR Analytics Dashboard transforms employee data into meaningful and interactive business insights using Power BI.

The dashboard is designed to help HR teams and business stakeholders understand:

* Employee attrition
* Workforce demographics
* Age-group attrition
* Job satisfaction
* Education-field attrition
* Years at company
* Average salary
* Average employee age
* Gender distribution
* Job-role analysis

The dashboard provides an interactive and visually engaging way to explore HR data and identify workforce trends.

---

## ⭐ Key Feature — Light & Dark Mode

One of the main features of this dashboard is the **Light Mode / Dark Mode toggle**.

A button located in the **top-right corner** allows the user to switch between:

### ☀️ Light Mode

A clean, bright interface designed for:

* Daytime usage
* Bright environments
* Easy readability
* Clean presentation

### 🌙 Dark Mode

A dark, professional interface designed for:

* Low-light environments
* Reduced visual brightness
* Modern dashboard presentation
* Comfortable viewing

The toggle allows users to change the dashboard theme without changing the underlying analytics.
